# Persnapse 랜딩페이지 시안

퍼스냅스 랜딩페이지입니다. 저장소 최상위 주소를 열면 팀이 선택한 1안이 바로 표시됩니다.

- [1안](./index.html)은 다음 연락 일정에서 출발해 기록과 관계가 이어지는 과정을 보여줍니다. [이전에 공유한 1안 주소](./concept-01-flow/)도 현재 첫 화면으로 연결됩니다.
- [2안](./concept-02-full/): 머릿속 생각 하나를 따라 깊이 들어가 문제 상황과 해결 과정을 보여줍니다.

정적 HTML, CSS, JavaScript로 만들었으며 빌드 과정이 필요하지 않습니다. GitHub Pages에서는 `main` 브랜치의 루트(`/`)를 게시하면 됩니다.

화면 속 상담과 고객 활동은 디자인·애니메이션 검토를 위한 가상 예시입니다. 앱의 최종 기능과 문구는 확정 전입니다.
